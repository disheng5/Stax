# StaxKit

> Hold'em, held right.

朋友局德州扑克的娱乐积分记录工具：快速开始、顺手记录、准确结算、看懂自己的数据。只记录积分和费用分摊，不提供支付或兑付服务。

## 当前状态

文档核对日期：2026-09-13；本轮来自 `codex/friends-ledger-polish`，开发基线：`5e0b4ea`，待发版本 `0.3.4`。合并、部署、上传与正式发布状态分别见 [发布记录](docs/RELEASE_0.3.4.md)。

优化代码已合入 `main`。本次云函数部署尝试失败且已验证现网源码未变，前端未上传；后续由用户按 [手动发布步骤](docs/RELEASE_0.3.4.md#手动发布步骤) 执行。

- 当前仓库包含可信记账、完整快照与静默同步、分享隐私、原地补资料、座位维度和趋势技巧轮换；本轮补充普通成员代买、创建防重复和统计边界修复。
- 本轮自动检查及开发者工具页面冒烟检查通过；包括首页、创建、我的、战绩、积分榜、详情和流水。尚未完成双真机、多账号写入与弱网端到端验收，不能把模拟器结果等同于真机性能结论。
- **没有独立 dev 云环境。** `miniprogram/app.js` 默认连接生产 `cloud1-d7gykoaktfc01fbf0`。云函数部署会立即影响已发布客户端。
- 根包、锁文件和关于页版本已统一为 `0.3.4`。这些标识不证明已正式发布，线上版本以微信后台与发布记录为准。

## 核心能力

| 模块 | 当前实现 |
| --- | --- |
| 积分记录 | 记住本人上次成功创建的配置、随机座位、分享邀请；开启共享时在场成员可互相代买，创建和加入可原地补资料 |
| 可信流水 | 全部记录倒序呈现，代操作人、修正和撤销可追溯；无 80 条等展示上限 |
| 结算与费用 | 全员结算自动结束，结束后三小时内可修正；费用单独记录，不计入积分盈亏 |
| 积分榜 | 赛季前三荣誉、成员列表、本人数据及记录；榜主管理权限单独处理 |
| 战绩分析 | 概览、趋势、人数/累计手数/星期/座位维度；座位按已记录的座位号分组 |
| 趋势解读 | 基于记录的规则解读，三十条技巧按本机账号的阅读次数轮换，不调用大模型 |
| 常用工具 | 术语词典、起手参考、概率计算器、规则速览 |

首页保留每日一字、底部语录和“分享 StaxKit”。参与入口使用微信分享，不提供手动输入邀请码入口；底层邀请码字段继续保留兼容。

撤销的云端处理与流水展示仍保留，但当前详情模板未绑定撤销操作入口。功能说明与验收需区分可见入口和旧调用兼容能力。

## 数据与体验原则

**数据准确 > 体验 > 性能。**

- 个人战绩使用本人可见、已结束的记录；按积分换算比例计算。本人隐藏、删除、本人已移出的记录不计入。不能仅凭记录名称自动识别测试数据。
- 详情优先同步呈现完整缓存，后台完整校准后再更新；相同数据不重绘。后台分页不等于向用户分批替换流水。
- 首页预热最近五场，完整房间持久缓存最多十二场；这不是单场流水条数限制。
- 实时订阅按页面生命周期管理，异常时静默恢复。弱网不能保证瞬时最新，未确认写入不伪装为成功。
- 分享卡片不带个人或房间统计，使用静态品牌图。页面隐私裁剪不等于底层读取权限已闭合，旧客户端直读依赖仍待迁移。

## 开发与验证

先读 [开发契约](AGENTS.md)。导入仓库根目录，使用有权限的小程序 AppID；现有项目不要随意更换 AppID 或环境 ID。

```bash
npm ci
npm run check
npm run lint
git diff --check
```

`check` 包含单元测试、实际函数入口/页面方法回归、Mock 全链路和文案扫描。测试数据库是内存实现，不访问生产。单独运行可用 `npm run test:regression` 或 `npm run test:mock`。

本轮本地验证使用 Node.js `v24.18.0`；测试用到了 `structuredClone`，不能沿用旧文档的 Node 14 要求。云函数运行时需另行核实，不能由本地 Node 版本推定。

纯本地演示见 [演示与回归](docs/DEMO.md)。只有明确切入 Mock 才不访问真实云；普通本地开发仍直连生产。
