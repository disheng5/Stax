## 邀请与分享

- [ ] 首页显示 StaxKit、Hold'em, held right.、每日一字；底部语录和分享入口保留。
- [ ] 创建页面常用配置、更多设置、娱乐积分说明正确。
- [ ] 创建时缺资料可原地补齐，取消保留表单；已具备资料不多等一次资料请求。
- [ ] 同页同表单双击、请求结果不明后重试只建一场；创建成功的完整快照在跳转前缓存。
- [ ] 仅成功创建后保存配置，按账号隔离；失败不覆盖上次配置，名称与成员不复用。
- [ ] 通过分享进入同一房间/积分榜；没有手动邀请码输入入口。
- [ ] 新用户可先查看，加入时原地填写昵称、选择头像和初始手数；取消不加入。
- [ ] 资料保存或加入失败后输入保留，连点不重复入场或记账。
- [ ] 记录结束后，受分享者可查看，但不能作为新玩家加入。
- [ ] 首页、战绩、房间、积分榜分享标题与图片均不含个人积分、胜率、房间流水或自定义名称。

## 账目与流水

- [ ] 买入手数、累计积分、已结算人数与成员列表一致。
- [ ] 共享开启时普通在场成员可帮其他在场成员补买，已结算者重新补买后恢复未结算；操作人正确。
- [ ] 共享关闭仍仅房主操作；旁观者不可代买，撤销和移出仍仅房主。
- [ ] 全员结算自动结束；有账差仍保留真实差额，结束后三小时内按权限修正。
- [ ] 费用分摊独立，既不扣减 `finalProfit`，也不影响个人积分胜率。
- [ ] 代操作人正确；修改结算可追溯前后值。
- [ ] 撤销兼容调用的回归通过：保留原记录，撤销事实使用实际时间与操作人，已确认剩余积分不被错误扣减。当前详情模板无撤销入口，不要求通过不存在的按钮验收。
- [ ] 全部流水倒序、同时间顺序稳定，不跨日分组、不隐藏早期流水。
- [ ] 结束事件按实际结束时间排序，后续修正显示在其上方；不无条件宣称全员已结算。
- [ ] 超过二十条、一百条的记录完整可见；分页失败不把已显示的完整列表缩短。
- [ ] 弱网重放期间新增操作不丢失，重复请求不重复入账，队列按账号隔离。
- [ ] 旧版无归属待提交队列不自动重放或删除，确认恢复后可继续提交。
- [ ] 派生统计失败保留任务；恢复后不重复累计，修正后最大赢亏也能下降。

## 页面与同步

- [ ] 首开完整数据一起呈现；重复进入不出现“下半部先出、整页再刷”。
- [ ] 相同数据返回不重绘；后台校准不清空当前完整内容。
- [ ] A 买入/结算/修正，B 停留详情，账目和流水同步为同一版本。
- [ ] A 结束/修正，B 停留战绩、我的或积分榜，正常网络自动追上结果。
- [ ] 改名换头像后，另一端当前房间和积分榜更新资料，不回退为“玩家”。
- [ ] 断网重连、前后台切换正常，隐藏页不保留新增高频订阅。
- [ ] 已单独测试首次未缓存头像、五场互切、弱网，以及超出近期订阅窗口的旧记录。
- [ ] 冷启动耗时、完整可读耗时与同步时延有实际记录，没有把目标写成实测结果。

## 积分榜与分析

- [ ] 积分榜前三、成员名单、本人数据符合当前展示设计；榜主管理与普通成员权限分开。
- [ ] 非成员、跨积分榜 seasonId 被拒绝；失去权限后不继续显示旧的详情缓存。
- [ ] 已确认页面裁剪不能证明底层完全不可读，权限迁移仍单独跟进。
- [ ] 赛季并发重算旧任务不覆盖新结果，排除和重置后统计口径一致。
- [ ] “重新计算本季积分”保留原始记录与排除设置；不暗示清零或删除原始积分。
- [ ] 赛季重算与本人记录排除历史 `deletedAt`；非法时长不误入赛季，个人隐藏不改变其他成员或积分榜结果。
- [ ] 战绩页人数、累计手数、星期、座位四个维度正确；座位数字升序，缺失值归“未记录”。
- [ ] 位置是座位号，不推断逐手行动位置；本人隐藏、删除、已移出记录不计入。
- [ ] 趋势解读仅引用对应时间窗口；三十条技巧轮换，后台同步不打断阅读。
- [ ] 同页反复展开不换句，已阅读后重新进入显示下一条；不发额外网络请求。
