## 位置口径

- 战绩页和独立维度页增加“位置”，使用记录中本人的 `players[].seat`。
- 按座位号升序排列，展示该位置的场次、盈亏、均值和胜率；只分析本人的结果。
- 没有座位号、座位号非法的旧记录归入“未记录”，不随机回填、不按玩家数组下标推测位置。
- 使用原有可见、已结束记录和积分换算口径；删除、本人隐藏、本人已被移出的记录不计入。
- 座位号不是每手轮换的按钮位、前位或后位。现有数据不能支持逐手行动位置的收益结论。
- 云端仅新增 `dimensions.position`，原字段保留；Mock 使用同一纯计算逻辑。
- 战绩主页面使用人数、买入次数、星期、位置四个维度；独立旧维度页另保留原“对手”入口，不作为本轮新增功能。

## 解读与小技巧

- 保留三段短文：可核实的数据观察、适合当前走势的视角、一条实用技巧。
- 数据观察涵盖近五场合计及前五场对比、正负场次、近期单场范围、连续负分；只使用对应窗口内的数据。
- 不满十场不比较两个不等长窗口；不满五场沿用不生成趋势解读的规则。不会对任意样本一律说“场次太少”。
- 心态与决策视角按近期结果分组，每组四种表达；不会通过积分推断打法优劣、性格或心理状态。
- 技巧从三条扩为三十条，交替覆盖决策复盘、行动位置、概率理解、情绪节奏、观察与交流、练习方法。采用条件化建议，不作胜率或结果承诺。
- 技巧按账号在本机轮换：重新进入页面后首次展开阅读才推进一次；未展开不消耗，反复折叠不更换，后台同步不更换。
- 轮换不请求云函数、不调用大模型、不依赖网络；原始记录变化时只重新计算真实观察，保持当前阅读的技巧不跳动。
- 云函数可选接受 `noteVariation`；未传或不合法的值使用默认值，不拒绝旧调用。

基础核对参考：观察行动过程、投入规模以及必要时休息，参考 [PokerStars Learn 的行动观察与情绪管理说明](https://www.pokerstars.com/poker/learn/strategies/action-research-tilt/)。本项目文案独立编写，不复制其示例，也不据此对玩家作诊断。
