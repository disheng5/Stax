## 手动发布步骤

### 1. 核对源码与检查

在仓库根目录执行：

```bash
git switch main
git pull --ff-only origin main
git status --short --branch
npm ci
npm run check
npm run lint
git diff --check
```

工作区有其他未提交改动时先核对，不用 reset 或清空数据来解决。根包、锁文件及关于页应为 `0.3.4`；上传时如微信后台已经有更新版本，先统一版本号再继续。

### 3. 编译与双账号验收

完成五个函数部署后重新编译，不清除全部本地数据。使用经授权的测试记录，重点确认：

- 旧线上前端仍能创建、加入、买入、费用分摊和结算。
- 新前端共享开启时普通成员能代买，操作人正确；共享关闭仍仅房主。
- 新用户原地补资料；取消保留表单；同页重复点击或结果不明后重试不会多建房间。

- 积分榜、战绩和个人统计同步；费用不计积分，历史修正没有重复累计。

不要拿真实朋友局测试删除、重算或改积分。真机头像选择、键盘、双机同步和弱网尚未在本轮实际完成验收，必须在这一步补齐。
