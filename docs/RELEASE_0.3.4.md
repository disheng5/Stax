## 本次内容

- 开启成员自助记录时，在场成员可互相代买，流水保留操作人；关闭共享仍仅房主。
- 创建原地补资料、同页重试防重复、跳转前完整初始快照、仅记住本人上次成功配置。
- 结束事件按实际时间排序，结束后的修正和费用变更在其上方；费用摘要不重做。
- 统计排除历史删除标记及赛季非法/缺失时间，修正累计手数、座位和重算入口表达。
- 保持完整缓存一次渲染、相同快照不重绘，不新增骨架或流水条数限制。
