# StaxKit 隐私说明草案

技术核对日期：2026-09-13；对应本地开发代码 `e722a8f`。

**本文是待运营方确认的说明草案，不代表已发布或已生效的隐私协议。** 运营主体、有效联系渠道、保留期限和平台披露仍需补齐。文档更新不会自动更新小程序页面或微信后台隐私配置。

## 处理的信息

| 信息 | 用途 | 触发场景 |
| --- | --- | --- |
| 微信 OpenID | 识别用户、关联资料、记录与权限 | 小程序连接云开发并获取身份时 |
| 用户填写的昵称、选择的头像 | 向获准查看记录/积分榜的用户展示身份 | “我的”保存资料，或邀请加入时原地完善资料 |
| 积分记录名称、配置、座位、买入、结算、操作人和时间 | 记账、同步、对账与个人分析 | 创建、加入、操作记录时 |
| 费用总额、方式与分摊结果 | 记录费用分摊，不计入积分盈亏 | 设置或调整费用时 |
| 积分榜成员、赛季、排除设置与排名摘要 | 赛季统计及权限管理 | 创建、加入或管理积分榜时 |
| 本地资料、头像地址、完整记录缓存 | 减少重复加载，支持完整页面呈现 | 浏览与更新记录时 |
| 待提交操作及操作编号 | 弱网续传和防重复 | 可重试写入未确认完成时 |
| 本机账号的技巧阅读序号 | 减少趋势技巧重复 | 实际展开阅读解读时 |

昵称和头像由用户主动填写或选择，不是点击“授权登录”后一并读取微信完整个人资料。选择头像会将所选图片上传云存储，不代表读取整个相册。

当前业务代码没有主动请求手机号、定位或通讯录。不能据此承诺微信和云服务商不处理其平台运行所需的信息；需另行核对平台及 SDK 披露。

## 存储与服务提供方

- 业务数据存放在腾讯云开发的数据库与云存储中，客户端通过微信与 CloudBase 能力访问。
- `wx.cloud.init` 当前启用 `traceUser: true`；运营方应核实相关平台数据处理，并在实际隐私披露中说明。
- 客户端会保存资料、头像地址、记录快照、待提交操作和阅读序号等，不是“所有数据仅在云端”。
- 当前趋势解读在本地依据统计与固定内容生成，不向外部大模型发送战绩。`aiReview/termAi` 的模型接入仍是占位实现，当前使用规则模板。
- 当前代码没有完整的业务数据到期清理或账号删除服务，不能承诺未实施的固定保留期限和自动删除时间。

若未来接入模型服务或新增其他数据处理，应先明确传输字段、服务提供方和使用目的，再更新用户披露。

## 分享与查看范围

- 分享卡片使用中性描述和固定品牌图，不直接显示个人积分、胜率或房间流水。
- 分享路径携带定位记录或积分榜所需的标识/邀请信息。收到邀请的人可以按产品流程打开相应内容，因此“卡片不显示数字”不等于“被邀请的人不能查看记录”。
- 当前房间邀请允许受分享者查看；未结束时可选择加入，结束后不可作为新玩家加入。
- 当前积分榜普通成员界面展示前三荣誉、成员名单和本人相关内容；榜主管理数据另按权限处理。
- **底层权限仍有历史兼容边界。** 旧客户端存在集合直读依赖，本轮未核实或迁移生产规则，不能承诺非授权原始数据在任何路径都不可读取。详情见 [云资源说明](CLOUD_SETUP.md#数据权限不要照抄旧规则)。

分享前请确认接收对象。未经他人同意，不把带真实成员信息的截图、导出数据用于公开展示或测试材料。

## 修改与删除

- 可在“我的”修改昵称和头像；历史操作中的身份快照与记账事实可能继续保留，不能承诺修改资料会抹去历史留痕。
- 在战绩页删除自己的记录，当前实现主要是从本人视角隐藏，不会删除其他参与者的账目或整场流水。
- 当前界面没有正式的“注销账号/彻底删除云端数据”入口；也不能把仅存在于代码中的缓存清理方法描述为可见按钮。
- 本地编译缓存、业务缓存、弱网待提交队列与云端数据不同。清除本地缓存不等于删除云端账号；不要在有待提交操作时随意清空全部本地数据。
- 云端删除申请的受理渠道、身份核验、共同账目保留范围和处理流程，需由运营方确认后提供。
